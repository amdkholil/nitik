# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Nitik, please send an email to Ahmad Kholil via [amdkholil@gmail.com](mailto:amdkholil@gmail.com). All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities through public GitHub issues.
